## 2.1 softjoint

`SoftJoint` 功能允许机器人在 **关节坐标系** 中对外部力量 **作出顺应性反应**，无需使用传感器。

<br>

### 语法

```plaintext
softjoint on
softjoint off
```

---

### 参数

| 参数 | 描述 |
|-----|------|
| on  | 启用 SoftJoint 功能 |
| off | 禁用 SoftJoint 功能 |

---
<br>

{% hint style="info" %}
在使用 `softjoint on` 命令之前，您必须使用 `softjoint_lim` 命令提前配置以下参数：

* 要顺应的关节索引 (` (j)`)
* 顺应级别 (`sft`)
* 限制角度 (`ang`)
* 门限值 (`thr`)

为了提高机器人对外部力量的敏感度，建议在执行 `softjoint on` 命令之前，使用 `时间延迟 (delay)` 命令使机器人停止约 **1-2 秒**。
{% endhint %}
<br>

{% hint style="warning" %}

此功能 **不支持辅助轴**。 
{% endhint %}
